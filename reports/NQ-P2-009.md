# NQ-P2-009 产品独立路由与可分享详情页修复报告

日期：2026-09-28
状态：已完成，等待用户验收

## 问题与验收标准

策略详情此前只存在于首页 Client Component 的内存和 sessionStorage 中。刷新后依赖旧缓存，外部用户无法通过稳定链接直达某个策略，搜索引擎也没有每个产品独立的标题、说明、canonical、Open Graph 或结构化数据。

本项验收标准：

1. 每个产品拥有唯一、稳定、可读的 slug；
2. 旧产品自动补齐 slug，新产品在创建事务内生成；
3. 产品改名不能破坏已经分享的旧链接；
4. `/market/[slug]` 服务端直出公开详情，不依赖浏览器缓存或登录；
5. 只有 `active + visible` 产品可以公开访问，下架、待审、隐藏和无效 slug 返回 404；
6. 页面包含动态 title、description、canonical、Open Graph、Twitter Card 和 JSON-LD；
7. sitemap 只收录公开产品；
8. 市场详情提供进入独立页面的入口，独立页面提供系统分享或复制链接；
9. 保留原有指标、证据、认证、版本、评分、收藏量和风险披露；
10. 完成隔离数据库、HTTP、404、sitemap、Lint、构建和 Git 验证。

## 实现

### 稳定 slug

`lib/product-slug.mjs` 统一执行：

- Unicode NFKD 规范化；
- 英文转小写；
- 移除组合音标；
- 非字母数字字符转为连字符；
- 保留合法中文文字；
- 标题部分最多 64 字符；
- 追加数据库产品 ID。

例如：

```text
TianWei_V1.46 + id 18 -> tianwei-v1-46-18
网格交易 + id 5         -> 网格交易-5
```

ID 后缀使同名产品仍然唯一。数据库建立 `idx_products_slug` 唯一索引。产品标题后续修改不会更新 slug，因此既有分享链接保持有效。

### 独立服务端详情

新增 `app/market/[slug]/page.js`。页面按照当前 Next.js 16 文档使用异步 `params`，在 Server Component 中读取产品；不存在或不可公开时调用 `notFound()`，由 Next.js 同时返回 404 和 noindex。

`lib/public-product.js` 只允许读取：

```sql
status = 'active' AND moderation_status = 'visible'
```

公开页面包含：

- 名称、作者、价格、品种、策略类型；
- 历史胜率和最大回撤文本；
- Nexus Verification 当前等级；
- 已审核结构化指标和曲线；
- 已批准 MT5 证据安全预览；
- MT5 报告摘要；
- 当前版本和版本日志；
- 永久授权用户评分与收藏聚合；
- 风险提示。

页面不返回私有报告文件、私有证据原图、程序文件路径或用户身份明细。

### SEO 与分享

`generateMetadata` 为每个公开产品生成：

- 独立 `<title>`；
- 最长 160 字的 description；
- canonical URL；
- Open Graph title、description、URL 和可用的产品图；
- Twitter Card；
- 缺失产品的 noindex metadata。

页面还输出 `SoftwareApplication` JSON-LD，包含应用名称、MT5 平台、作者、价格、公开 URL，以及有评分时的聚合评分。

根 layout 新增 `metadataBase`。`.env.example` 增加 `NEXT_PUBLIC_SITE_URL`，生产部署必须设置为实际 HTTPS 公网域名。

新增 `/sitemap.xml`，只列出首页、市场和 `active + visible` 产品详情。隐藏或下架策略不会进入 sitemap。

独立页面的分享按钮优先调用系统 Web Share API；浏览器不支持时复制当前完整 URL。原市场详情增加“打开可分享页面”入口。

## 残余边界

- 当前策略 logo 使用私有上传系统产生的公开安全 URL；如果未来迁移到对象存储，需要同步配置 Next Image 或继续使用安全代理 URL。
- 分享卡片在社交平台上的最终预览依赖正式 HTTPS 域名可从公网访问；本地构建只能验证 metadata HTML，不能让外部抓取机器人访问本机。
- 产品删除受既有订单、版本和审计约束；不能删除的产品应继续使用下架或内容隐藏，独立 URL会自动返回 404。
- 真实付费能力仍保持关闭，本项没有改变订单、支付、结算或提现上线状态。

## 结论

NQ-P2-009 已达到验收标准。每个公开产品现在具有稳定、可分享、可索引的独立地址，隐藏和下架内容不会泄漏；旧产品完成兼容迁移，新产品创建时原子生成 slug，改名不会造成历史链接失效。
