# NQ-P1-008 CSRF、Origin 与凭证化 CORS 修复报告

复核日期：2026-09-26

## 问题与结论

修复前 Session Cookie 使用 `SameSite=Lax`，但所有 API 写接口没有统一服务端来源验证。SameSite 能降低部分跨站表单风险，不能替代严格 Origin 检查，也不能保证未来 Cookie 属性、跨子域部署或浏览器行为变化后仍安全。各路由独立实现会产生遗漏风险。

本项已完成：根级 Next.js 16 `proxy.js` 覆盖 `/api/:path*`，所有 22 个 `POST/PATCH/PUT/DELETE` 方法在进入 Route Handler、业务查询和限流前验证来源与内容类型；生产必须配置精确 HTTPS `APP_ORIGINS`；缺失、`null`、畸形或不允许来源返回 403；拒绝事件进入签名审计链；允许的独立前端域获得凭证化 CORS 与预检支持。

## 来源验证规则

对于 POST、PUT、PATCH、DELETE：

1. 如果配置了有效自动化 Bearer Token，跳过浏览器来源检查；业务 Session/RBAC 仍正常执行。
2. 存在 `Origin` 时，必须是精确 HTTP(S) origin，不能为 `null`，不能含路径、查询、片段或凭据。
3. 没有 `Origin` 时，仅使用 HTTP(S) `Referer` 的 origin 作为回退。
4. 解析出的 origin 必须精确出现在 `APP_ORIGINS`。
5. 不使用 Host、X-Forwarded-Host 或 X-Forwarded-Proto 推导生产允许来源。

生产配置要求：

- 至少一个 `APP_ORIGINS`；
- 每一项都必须是 HTTPS；
- 不允许尾部斜杠；
- 不允许路径、查询、片段或用户名密码；
- 多个来源用逗号分隔并精确匹配。

## Content-Type 与 CORS

- 普通有正文写接口要求 `application/json`。
- `/api/upload` 要求 `multipart/form-data`。
- `/api/auth/me` 注销请求没有正文，是明确例外。
- DELETE 当前没有正文，是明确例外。
- 不匹配返回 415 `CONTENT_TYPE_REJECTED`，并在业务解析前结束。

允许的跨域前端获得：

- `Access-Control-Allow-Origin` 精确回显允许来源；
- `Access-Control-Allow-Credentials: true`；
- 明确的方法和请求头列表；
- `Vary: Origin`；
- 合法 OPTIONS 预检返回 204；
- 不允许的预检返回 403 并审计。

没有使用通配符 Origin，因此不会把带 Cookie 的接口开放给任意站点。

## 非浏览器自动化

可选 `CSRF_AUTOMATION_SECRET` 至少 32 字符，通过：

`Authorization: Bearer <CSRF_AUTOMATION_SECRET>`

仅绕过 Origin/Referer 验证。它不会创建用户 Session，也不会绕过 RBAC、限流、schema 或资源所有权检查。需要调用受保护接口的自动化仍必须携带正常认证。错误 Token 会继续进入来源验证，不能降级为匿名放行。

## 接口覆盖

生产运行时逐项验证了 22 个写方法：send-code；withdraw POST/PATCH；register；posts POST/PATCH/DELETE；orders POST/PATCH；comments POST/PATCH/DELETE；upload；users PATCH/DELETE；settings POST；password reset；logout；products POST/PATCH/DELETE；login。项目当前不存在 PUT 方法，但策略会自动覆盖未来 `/api/*` PUT。

每个方法使用恶意 Origin 请求时均返回 403 `CSRF_ORIGIN_REJECTED`，`X-Audit-Status=ok`，没有进入各 Route Handler。

## 运维边界

1. 正式域名确定后，把每个实际前端 origin 精确写入 `APP_ORIGINS`；预览域名不能用通配符批量开放。
2. 入口反向代理必须保留浏览器 Origin/Referer，不能统一删除或改写。
3. 自动化 secret 应独立保存、最小分发并定期轮换；浏览器前端绝不能持有该 secret。
4. 域名、协议、CDN 或前后端分域发生变化时，必须重新执行预检、Cookie 和全部写接口验收。
