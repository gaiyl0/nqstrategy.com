## 已确认规则

- 核心流程：浏览 EA → TMGM 注册并入金 → 提交客户资料 → 管理员核验 → 获得 200 奖励积分 → 兑换下载 → 论坛交流。
- 不得写成注册即送；EA 积分价超过余额时显示差额。保留奖励来源不可形成开发者可提现分成的规则。
- 先审查示例图，再实施页面代码。第一期面向独立部署的一套品牌配置，不默认建设多租户平台。

## 配置能力与验收

| 分组 | 配置范围 | 验收标准 |
| --- | --- | --- |
| 品牌资料 | 名称、Logo、favicon、简介、联系方式、社交链接、默认 SEO 标题与描述 | 头部、页脚和元信息同步更新，不残留硬编码品牌 |
| 站点预设 | EA 积分站、独立商城、品牌展示，可逐项覆盖 | 切换前预览变更；不清空用户、订单、商品、积分或帖子 |
| 导航与页面 | 标题、排序、显示、内部页面、外部链接；新建品牌、服务与介绍页 | 手机与桌面一致；处理菜单溢出；禁止危险 URL；页面标识唯一且不覆盖系统路由 |
| 首页模块 | 首屏文案与图片、精选商品、推广、任务、论坛动态、指南、图文、品牌介绍及按钮 | 可排序与开关；空模块收缩；禁用功能不留下悬空入口 |
| 功能开关 | 论坛、商品目录、积分任务、公开发布入口 | 隐藏入口与停用功能明确区分；服务端/API 同步限制；导航与站点地图一致 |
| 样式展示 | 现有/新主题、强调色、图片、内容宽度及密度 | 管理员设定全站主题，共用业务数据；手机不溢出；正文可读 |
| 配置发布 | 草稿、预览、发布、版本与回退 | 草稿不影响访客；发布原子生效；回退不修改业务数据；记录管理员操作 |

自定义页面优先采用受约束的富文本与模块组合，禁止任意脚本或未过滤 HTML。支付开关仍要求既有服务端凭证与试点条件，不能仅靠展示设置开放。

论坛设置分为仅隐藏导航和停用公开论坛功能；停用保留历史帖子、回复与附件，可恢复。发布停用配置前预览已有文章地址的保留阅读或跳转策略，不把所有文章简单跳首页。停用后发帖与回帖奖励同步停止接受新请求。

独立商城第一期复用数字商品、积分与下载能力；实体商品规格、库存、物流、运费及独立现金结账需另行实现。品牌展示模式可关闭兑换与任务入口，保留品牌、产品与联系页。

## 页面与后台

- 全站默认主导航：首页、EA 下载、论坛、赚积分；个人中心由头像进入。导航可按品牌修改。
- 个人中心只保留个人功能；开发者增加发布、销售与提现。无真实收益数据时缩减空状态，突出已兑换 EA、下载、任务和通知。
- 论坛移除新闻、策略速览、文档与策略库主标签；有用资料保留并处理旧地址。初期集中黄金 EA、使用问答、回测参数、平台与新手四类。
- 论坛采用分页、最新发布/最新回复/待解答筛选，增加问题解决状态、回复通知与 EA 官方讨论帖。手机优先阅读和回复。
- 后台分工作台、EA 管理、任务与推广、论坛运营、用户与积分、网站设置、系统维护。审核、资料补充、发积分与通知形成连续流程，不重复发放。
